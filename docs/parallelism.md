# Parallelism

The [Queue][dexter.Queue] type can utilize multiple threads when running particle routines. To set the number of threads use [`set_num_threads`][dexter.set_num_threads]:

::: dexter.set_num_threads

To get the number of threads available on your system, use [`get_max_threads`][dexter.get_max_threads]:

::: dexter.get_max_threads
