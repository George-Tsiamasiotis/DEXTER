# $E-P_\zeta$ Positions

The diagram below shows the standard orbit types in the LAR configuration.

[`EnergyPzetaPosition`][dexter.EnergyPzetaPosition] and [`OrbitType`][dexter.OrbitType] variants correspond to  one of the below $E-P_\zeta$ regions.

| Symbol      | Orbit Type                   |
| ----------- | ---------------------------- |
| $P_+ - C$   | Co-Passing - Confined        |
| $P_+ - L$   | Co-Passing - Lost            |
| $P_- - C$   | Counter-Passing - Confined   |
| $P_- - L$   | Counter-Passing - Lost       |
| $T - C$     | Trapped - Confined           |
| $T - L$     | Trapped - Lost               |
